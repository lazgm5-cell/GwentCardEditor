# GWENT Card Editor 0.3.123

## Скачать

- Исходный код версии 0.3.123: [GwentCardEditor-0.3.123-Source-Public](https://github.com/lazgm5-cell/GwentCardEditor/tree/main/GwentCardEditor-0.3.123-Source-Public).
- Архив Windows x64 подготовлен отдельно и будет опубликован как GitHub Release asset.
Простой редактор подтверждённых параметров карт и лидеров GWENT.
Неоднозначные и несовместимые структуры не должны обходиться ручной правкой
служебных значений. Автоматические проверки не заменяют проверку поведения в игре.

## Текущее состояние

- Основные характеристики, проверенные числовые параметры способностей и совместимые добавляемые ключевые слова.
- Изменения способностей действуют только в режиме тренировки против ИИ; на сетевые матчи они не влияют.
- Статичные арты и изображения рубашек, пользовательский звук, глобальное оформление и откат пакетов.
- При первом открытии клиента исходный `data_definitions` сохраняется в `%LOCALAPPDATA%\GwentCardEditor\DefaultDataDefinitions` и не перезаписывается автоматически; кнопка «Открыть исходную базу» показывает копию в Проводнике.
- Согласование описаний с подтверждёнными изменениями количества целей, добора, сброса и переноса карт.
- Выбранный добор: Миргтабракке, Проклятый свиток, Маневр и Селективная мутация.
- Перенос из руки: восемь подтверждённых вариантов; сброс: Коралл, Хэймэй: скальд и Маска Уробороса.
- Аудит всех видимых числовых настроек с отдельной очередью уточнения и игровым чек-листом.
- Проверенные начальные статусы отрядов: названия применённых статусов автоматически добавляются в описание карты на языке клиента и обновляются при изменении переключателей.
- Причины заблокированных начальных статусов доступны в подсказках у соответствующих флажков.
- Изменения автоматически собираются в общий черновик. Окно проверки показывает правки по картам, позволяет продолжить редактирование выбранной карты или удалить все её изменения.
- Источник данных виден в строке состояния вместе с SHA-256 архива; приложение предлагает официальный путь GOG и позволяет быстро вернуться к нему.
- Снимок Совета баланса поддерживает официальную GOG-базу с проверенным хешем; неизвестные версии базы по-прежнему блокируются.
- При переходе между картами изменения собираются в общий черновик; в окне проверки можно открыть карту для правки или удалить её изменения.
- Версия 0.3.114 завершила перевод интерфейса на все 13 языков клиента. Версия 0.3.115 убрала статичный эскиз и отчёт охвата статусов. Версия 0.3.116 добавляет общий черновик для редактирования нескольких карт.
- Версия 0.3.117 позволяет применить одно изображение сразу ко всем семи поддерживаемым стандартным рубашкам. Бронзовые и золотые рамки и раньше настраивались глобально и независимо.
- Версия 0.3.118: подтверждение правок в окне проверки запускает создание пакета для установки; исходный клиент остаётся без изменений.
- Версия 0.3.119 позволяет собирать пакеты оформления при наличии несохранённых изменений карт и включает полный ArtRuntime в сборку.
- Версия 0.3.120 разрешает собирать общее оформление после установки собственного пакета способностей в открытую сессию клиента.
- Версия 0.3.121 позволяет один раз задать папку экспорта и добавляет поддержку дополнительных способностей для Старого медведя и Духа Леса.
- Версия 0.3.122 поддерживает добавление способностей в исходно пустые графы Старого медведя и Духа Леса.
- Версия 0.3.123 сохраняет неизменённый `data_definitions` при первом открытии клиента и добавляет общий откат графических пакетов одной кнопкой.

## Аудит И Проверка

Повторный экспорт из одной открытой сессии разрешён после применения её
собственного пакета: архив клиента должен побайтно совпадать с известным
результатом этой сессии, а исходная копия в пакете — с её исходным архивом.
Новый пакет содержит все текущие изменения сессии и собирается от исходной
копии, без повторного применения уже внесённых правок и Совета Баланса.
Папки пакетов с `_editor/backup` нельзя удалять до завершения такой работы.
Неизвестные внешние изменения по-прежнему останавливают экспорт; при ошибке
не следует закрывать редактор с несохранёнными изменениями.

Экспорт аудита доступен через существующий параметр запуска из папки с
`GwentCardEditor.exe`:

```powershell
.\GwentCardEditor.exe --client "C:\Games\GWENT" --meaning-audit "C:\GWENT_Audit"
```

Нужно указать свои пути. Выходная папка должна быть новой: существующая папка
не перезаписывается. Аудит не применяет изменений к клиенту.

- `readiness-summary.json`: сводка по всем видимым настройкам, языкам и приоритетам.
- `REVIEW_QUEUE_RU.md`: сгруппированная очередь, без требования вручную описывать каждую карту.
- `GAMEPLAY_CHECKLIST_RU.md`: короткая ручная проверка, отдельно от результатов автотестов.
- `ability-meanings.json`: исходные тексты, ID параметров и признаки графа для технического разбора.
- `semantic-locks.json`: распознанные технические значения, уже исключённые из простого редактора.

Пометка «уточнить» не означает найденную ошибку. Отсутствующая в исходнике
локализация не считается сломанным переводом. Наличие связи с описанием не
означает, что карта уже проверена в игре.

Версия 0.3.114 добавляет повтор действий и окно истории с групповым undo/redo,
фильтрацию списка карт по имени, фракции, редкости, категории и включённому
исходному статусу, а также проверку пакета арта перед установкой и кнопку отката
после неё. Версия 0.3.116 позволяет редактировать несколько карт до общего
подтверждения. Для арта требуется открыть проект из полной установки GWENT.
Подробности по текущей версии см. RELEASE_NOTES_0.3.116_RU.md. Редактор остаётся ограниченным проверенными
настройками; произвольный конструктор сложных способностей не входит в его область.
Архив Windows x64 включает .NET runtime и не требует отдельной установки .NET.

## История До 0.3.90

Ниже сохранены исторические заметки; упоминания «следующих этапов» относятся
к соответствующим старым версиям, а не к текущему списку работ.

Завершён безопасный этап добавляемых ключевых слов: добавлено Безумие
для 28 отрядов Синдиката с подтверждённым фиксированным Платежом.
Переключается штатное поле Madness без изменения узлов способности;
описания обновляются автоматически. Штатное Безумие не удаляется.
Условные ключевые слова без самостоятельного эффекта не предлагаются
как переключатели. Следующие этапы: импорт изображений рубашек и
синхронизация количества целей с описанием карты.

32 дополнительные созданные/производные карты перенесены из обычных карт
в группу «Токены». Это только группировка каталога: игровой флаг токена,
доступность, параметры и контракты редактирования не меняются. Переходы
к связанным картам автоматически выбирают группу «Токены».

Добавлен «Обход» (Flanking): флажок во вкладке «Способность» для 20 отрядов
с подтверждённой цепочкой конца своего хода. Используются штатные SubAbility
51 и цикл повторения: в рукопашном ряду повторяется исходная цепочка,
в дальнобойном выдаётся броня при штатном условии соседства. Описания
обновляются автоматически. Исходные числовые настройки сохраняются,
удаление восстанавливает исходное соединение. Неоднозначные цепочки
и уже существующий Обход не переписываются. Игровая проверка ещё нужна.

Добавлено «Эхо» (Echo): флажок во вкладке «Способность» для 135 совместимых
особых карт. Переносится полная штатная ветвь с отдельной постоянной
переменной и логикой Обречённости, без изменения исходной способности.
Описания обновляются во всех имеющихся локализациях. Удаление восстанавливает
исходный граф и его переменные. Штатное Эхо и неоднозначные сочетания
не переписываются. После экспорта требуется проверка в игре.

Добавлено «Восполнение» (Resupply): во вкладке «Способность» его можно
добавить 15 отрядам с подтверждённым кулдауном. Используется штатное
уменьшение кулдауна на 1 при розыгрыше военного искусства. Описание
автоматически добавляется во все имеющиеся локализации. Кулдаун остаётся
редактируемым, удаление ключевого слова восстанавливает исходную ветвь.
Уже существующее Восполнение и несовместимые случаи не переписываются.

Добавление Выгоды: вкладка «Способность», флажок «Выгода» и число от 1 до 9.
В оригинальной базе поддержаны 77 совместимых карт Синдиката, включая
двухфракционные карты, особые карты и артефакты. Добавляется штатная
независимая ветвь IncomeTrigger → общая способность 16. Описания обновляются
во всех имеющихся локализациях. Уже существующая Выгода редактируется
прежними числовыми полями. Неподтверждённые структуры блокируются.

В «Параметры» → «Категории» доступны все шесть банд: Дети Огня, Златорубы,
Сердцееды, Тени прилива, Невидимые и Саламандра. Можно добавлять, удалять
и сочетать категории. Маски остальных категорий сохраняются; названия
берутся из локализации клиента. Основная категория также понимает банды.

Проверены ещё девять карт. Скрыты служебные выборы Исбель и Драки в корчме,
минимум целей Петера, два внутренних счётчика создания Удара милосердия,
нулевые усиления Кальвейта и Падшей Райлы. У Языка мертвеца подписаны первое
и дополнительное бронзовое удаление, у Беглого чародея цели с Данью и без,
у Григора урон выбранному отряду от Платежа и всем врагам от Берсерка.
Неизвестные варианты трёх графов не получают предположительных подписей:
соответствующие поля блокируются, включая прямой API. Клиент не изменяется.

Скрыты служебное создание сущности лидера у Анны и Дамьена и нулевые
сигнальные усиления Дамьена и Инженера. Два числа Иллюзиониста подписаны
как обычная ветвь и Взаимосвязь. Записи фракций Type=0 исключены из списка,
в том числе при показе скрытых карт. Неактивные чекбоксы читаемы на чёрном
фоне; контраст текста проверяется по светимости, без изменения доступности.

Проверены Горд, Ширру, Кнут, Мелюзина, Бран, Скьёрдаль, Ульфхединн и
Ромпалли. Скрыты техническое восстановление приказов и фиксированное число
целей Ромпалли. Собственный Ветеран и его число объединены в одном контроле;
усиление отрядов Браном в начале игры подписано отдельно. У Отвара из
гигаскорпиона редактируются варианты: урон каждого из шести ударов и общий
случайный урон. Режимы безопасно разделяются при первом изменении.

Исправлен перенос переключателей для длинных строк: учитываются видимая
ширина панели и место полосы прокрутки. Дополнительно проверяются границы
всех семи сценариев врождённых способностей на трёх языках.

Добавлены отдельные постоянные переменные врождённых ключевых слов.
Общее покрытие: 40 параметров Ассимиляции, Гармонии, Устрашения и Симбиоза.
Поддерживаются как неявное значение 1, так и штатные подстановки чисел
в описаниях. Значение 2 у Гармонии и Ассимиляции также редактируется.
Общие переменные, runtime-записи и неоднозначные подстановки блокируются.

У подтверждённых постоянных входов врождённых Ассимиляции, Устрашения и
Симбиоза поле усиления подписано ключевым словом и синхронизирует описания.
На оригинальной базе подтверждён 21 параметр. Диапазон 1–99; вычисляемые
входы, неоднозначные упоминания и несовпадающие тексты не допускаются.
Врождённые способности по-прежнему нельзя снять галочкой.

Для добавленных Ассимиляции, Гармонии, Устрашения и Симбиоза доступно
усиление от 1 до 99 рядом с переключателем. Число применяется к отдельному
входу модуля и синхронно добавляется в описания всех существующих языков.
Старые модули со значением 1 совместимы. Врождённые способности через эти
поля не изменяются. Сродство, Ветеран и Строй остаются фиксированными.

Добавлен Строй (Formation): рвение в рукопашном ряду или усиление на 1 в
дальнобойном. Доступен для совместимых отрядов с существующим приказом;
новый приказ не создаётся. Постоянное рвение, обработчики розыгрыша и
непрозрачные подспособности исключены. Описания обновляются автоматически.
Добавленный модуль можно удалить. Требуется игровая проверка.

Добавлен обычный Ветеран: нативное увеличение изначальной силы на 1 между
раундами. Сохраняются ограничение раундов и общая обработка блокировки.
Описание добавляется в существующие локализации. Врождённый Ветеран readonly,
удаляется только модуль редактора. Требуется игровая проверка.

Добавлен обычный Симбиоз (Thrive, усиление на 1) с автоматическим описанием
в существующих локализациях. Используется нативная общая проверка силы
и стороны игрока. Сродство и Симбиоз остаются разными механиками.
Один добавленный модуль на карту, исходные способности сохраняются.
Нужна игровая проверка.

Добавлено обычное Устрашение (1) с автоматическим описанием в локализациях.
Переносится отдельная нативная ветка, без замены исходной способности.
Переключатели дополнительных способностей размещены под отдельным заголовком.
Требуется игровой тест; игровые файлы автоматически не устанавливаются.

Добавлена обычная Гармония (1) с автоматическим описанием на доступных языках.
Для ассимиляции и гармонии используется общий проверяемый механизм автономных
модулей, сохраняющий исходные узлы и локальные переменные карты. Прежние
добавленные модули ассимиляции остаются совместимыми. Требуется игровой тест.

Добавлена обычная Ассимиляция (1) в дополнительные способности. Переносится
нативная автономная ветка с проверкой стартовой колоды; исходные способности
не заменяются. Описания обновляются во всех существующих локализациях карты.
Пока допускается один добавленный модуль на карту; врождённые способности
сохраняются. Требуется игровое испытание.

Первый дополнительный модуль: обычное Сродство. На вкладке способностей
появился переключатель для совместимых отрядов. Он добавляет нативный маркер
и описание во всех доступных локализациях, не заменяя исходную способность.
Врождённое сродство не удаляется. Добавленный редактором модуль можно снять,
в том числе после экспорта и повторного открытия. Игровое испытание требуется.

Из обычного интерфейса скрыта техническая диагностика переменных и связи
числовых параметров с описаниями, включая подтверждение изменений.
Понятные пояснения действия настроек и фрагменты описаний сохранены.
Внутренние проверки, аудит и блокировки не менялись.

Добавлен лимит усиления Харальда Горда: синхронно меняются фактический предел
общего счётчика и число в описании. Скрыт нулевой удар Ширру перед уничтожением.

Уточнено общее усиление Барнабы. У Волчьей ямы доступен общий урон Броска
вместо технического размера попадания. Настройки Единения с природой вынесены
в три карты выбора: усиление каждого варианта, длительность выносливости
и явно обозначенное общее количество целей. Исполняемый граф и описания
вариантов синхронизируются при применении, экспорте и откате.

Добавлены проверенные вычисляемые настройки Филиппы: слепой ярости
(выбранная цель и начало трёх случайных ударов с шагом -1) и Боевого слона
(согласованная пара обычного и удвоенного усиления). В подтверждении изменений
связанные числа свёрнуты в один понятный пункт. Скрыты служебное усиление
Странствующей жрицы и обнуление брони Трололо. Порог зарядов Радовида: наказание
остаётся скрытым. Процедуры способностей не переписываются.

Разблокированы начальные заряды Каэдвенского сотника после отдельной проверки
вызова Строя. Скрыты технические проверки неиспользованного приказа/отсутствия
зарядов, нулевое усиление Короля Радовида V и количества вскрытия самой Мелитэле.
Явные параметры зарядов и реальное добавление зарядов Радовидом остаются доступны.

Добавлена начальная выдержка (0-99) для Кейры Мец, Герхарта из Аэлле,
Истредда, Ученика из Бан Арда, Ученицы из Аретузы и Медитирующего чародея.

процедуры приказа не переписываются. Неоднозначный вариант Летиции заблокирован.

Кровавая кукла: дублирующиеся настройки целей двух альтернативных ветвей
объединены; удаление фиксировано на одной карте, от которой берётся сила.
Скрыты служебная проверка неиспользованного приказа Медоносного призрака
и число рядов Шабаша ведьм, передаваемое графом как одно значение ряда.

Скрыты не связанные с числом в описании нулевые проверки силы/брони и единичный
технический отбор сильнейшего/слабейшего отряда. Убраны спорные поля Витольда,
Ирис, Исполинской жабы и Имлериха: гнева. Явные пороги вроде 4 у Киприана
Вилли и 9 у Геральта остаются редактируемыми.

Скрыты технические количества уровней силы при отборе сильнейших и слабейших
карт. Явное количество карт и числовые пороги силы остаются доступными.

Уточнены настройки Ольгерда: Бессмертного, Сианны, Офирского торговца,
Селективной мутации и Эльфо-лукового супа. Служебные нулевые эффекты скрыты;
вскрытие после обмена, добор, замешивание и дополнительные цели подписаны отдельно.
Первый выбор супа, определяющий цвет рамки, защищён от изменения.

Фильтры брони больше не называются порогом силы. Служебная проверка выживания
после урона (например, Испытание Травами) скрыта и защищена в backend.
Для простого сценария «выбрать карты и сразу взять выбранные» одинаковые границы
выбора и число добора объединены в одну настройку, которая меняет все три числа
согласованно. У Миргтабракке отдельно подписан возврат выбранных карт вниз колоды.
Неравные или неоднозначно связанные количества не объединяются автоматически.

Скрытие в каталоге редактора больше не определяется Availability=0. Символы,
лидеры и прочие служебные варианты показываются без «Показать скрытые».
Исключения: 202290, 202395, 202394, 203190, 202570, 202571 и DebugName Data only card(s).
Туториал по-прежнему исключён из каталога. Скрытые исключения остаются доступны
для просмотра через явный фильтр, без разблокировки их редактирования.
Availability и данные коллекции в игре не изменяются.

Стратегические приёмы поддерживают текст, оформление и подтверждённые числа
способностей. Сила, броня и неиспользуемая стоимость найма не редактируются.
Для стратегических приёмов и записей Availability=0 используются локальные
значения, без поправок Совета Баланса.

Уточнена группа создания копий: источник шаблона, владелец новых карт, зона создания,
положение сверху/снизу колоды и подтверждённые относительные позиции. Заранее
заданные карты отличаются от копирования шаблона выбранной карты. Учитывается
реально подключённый вход размещения, а не неиспользуемые значения по умолчанию.
Точное толкование применяется только при совпадении проверенной подспособности.
Изменяемые во время игры источники не угадываются по начальному значению.

Все доступные числовые настройки получили пояснения типа изменения. Где подтверждено
графом, показаны действие над выбранной картой, получатель эффекта, операция,
знак сравнения и создаваемая карта. Для связанных с текстом переменных показывается
фрагмент игрового описания с пометкой `[это значение]`. Это не подстановка по совпавшему числу.
Равные независимые границы выбора карт/вариантов объединены в одно поле.
Небезопасные границы выбора скрыты, если граф использует только первую выбранную карту.

Снимок структурного аудита до расширения каталога в 0.3.59: `Reports/AbilityMeanings_0.3.58/REPORT_RU.md`.
Он не заменяет проверку каждой карты в игре. Неуточнённый контекст вынесен отдельно
в `needs-review.json`, а не объявлен полностью проверенным.
Повторный аудит своего клиента: `publish-0.3.76/GwentCardEditor.exe --client "ПУТЬ" --meaning-audit "НОВАЯ ПАПКА ОТЧЁТА"`.

В панели чисел убран технический счётчик «Использований». Отбор сильнейших/слабейших
отрядов и уровней силы теперь различается в названии и пояснении, вместо общего
«Порог силы». Настройки числа рядов скрыты и заблокированы, если граф использует
только первый выбранный ряд (например, Охотник школы Грифона).

Исправлено чтение звукового каталога клиента, где один XML-блок содержит
несколько звуковых определений. Дубликаты ID и неизвестные структуры по-прежнему блокируются.

Пакеты с резервными копиями по умолчанию сохраняются в `Backups` рядом с `CardEditor.cmd`
(в переносной сборке без launcher — рядом с EXE). Для каждого клиента создаётся отдельная папка.
Имя пакета содержит дату, время и тип правки; `PackageInfo.txt` содержит полный путь клиента
и описание. Повторное сохранение не перезаписывает прежний пакет. Другую папку можно выбрать вручную.
Кнопка «Открыть папку бэкапов» находится во вкладке «Оформление». Старые пакеты не перемещаются.
Диагностические отчёты и настройки по-прежнему находятся в папке настроек редактора.

## Русский
