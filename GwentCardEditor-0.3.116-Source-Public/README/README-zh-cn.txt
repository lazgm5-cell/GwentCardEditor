GWENT 卡牌编辑器
用户指南（测试版）

完整界面支持全部 13 种语言：英语、俄语、简体中文、繁体中文、德语、
西班牙语（西班牙和墨西哥）、法语、意大利语、日语、韩语、波兰语和
巴西葡萄牙语。部分翻译由机器生成，可能存在不准确之处。卡牌类别名称
读取所选客户端的游戏本地化文件。“卡牌文本”区域默认打开英语标签。

1. 启动并打开客户端

运行 GwentCardEditor.exe。首次启动时界面语言为英语，可在语言列表中更改。
选择“打开 GWENT 客户端”，然后指定 GWENT 安装文件夹。编辑器会读取该
客户端的数据；编辑和“应用更改”不会直接写入游戏。

左侧是卡牌列表。使用阵营标签、类别筛选器和搜索框查找卡牌。可以按名称
或卡牌 ID 搜索。点击列表标题可排序，再次点击可反转顺序。普通卡牌、
衍生物和领袖分别显示在对应类别中。选择卡牌后可编辑其参数。

2. 卡牌编辑区域

参数
只修改当前卡牌中已启用的项目：战力、护甲、牌组构筑费用、稀有度、主要阵营、
可选的次要阵营和类别。两个阵营必须不同。更改阵营不会改写卡牌能力的条件或目标。
领袖的费用字段表示领袖的牌组费用加成。初始状态和其他已验证的
开关仅在支持该卡牌时可用。禁用的控件代表该项尚未验证，不可修改。

能力
这里显示该卡牌现有能力中已验证的数值，例如伤害、增益、目标数量、充能、
计时器或费用。字段旁的说明解释其用途。若某个数值也出现在卡牌描述中，
编辑器会同步更新受支持的描述。应用前请检查变更列表。通过编辑器修改的
卡牌能力只在对战电脑的训练模式中生效；多人对战中不会生效。

卡牌文本
每个标签对应所选客户端中可用的一种语言。可以编辑卡牌名称、能力描述和
风味文本。默认打开英语标签。客户端原本没有的文本条目不会自动创建。
请保留格式标签和变量标记；单行游戏文本中不要直接按 Enter 换行。

卡牌插画
选择图片，在预览中调整位置和裁切，然后导出插画包。安装和恢复插画包是
单独的操作。普通插画替换不会改变闪卡动画。

卡背
选择替换图片并导出卡背包。安装前请关闭游戏。包中包含用于恢复的备份。

全局外观
预览并选择受支持的卡框和卡面元素。这些设置会影响相应卡牌组，而不是
仅影响当前选中的卡牌。动画卡框和隐藏初始牌组需要额外的 BepInEx 组件；
编辑器会在相关选项旁显示要求。静态卡框不需要加载器。

音频
如果此功能对当前卡牌可用，可以使用另一张卡牌的游戏音频，或为闪卡预览
准备自定义片段。自定义音频需要额外插件。导出音频包不会自动安装它。
安装或恢复前请关闭 GWENT，并按编辑器提示操作。

3. 平衡委员会

“平衡委员会”默认启用。编辑器使用从官方 playgwent.com 牌组构筑器获取并
保存在本地的投票快照。点击“更新平衡数据”下载最新快照；每次平衡委员会
变更后都应重新更新，快照不会自动刷新。启用时，显示的战力和牌组费用会
包含快照调整，导出时编辑器会针对所选客户端处理该调整。关闭后只使用客户
端本地卡牌数据，例如客户端不包含平衡委员会调整时。请勿在编辑过程中途更换数据源。

4. 应用、撤销和导出

编辑一张卡牌后可以直接选择下一张，所有修改会自动汇总到项目草稿中。
“应用更改”会打开按卡牌分组的列表。选择卡牌可继续编辑，也可删除该卡牌的全部修改。
“撤销”和“重做”作用于整个草稿。“应用更改”只确认编辑器项目中的修改，不会写入游戏目录；
“全部重置”会清除当前会话中的修改。导出会创建包含这些修改的新数据包。

导出会创建新的输出文件夹，不会覆盖所选客户端。请选择尚不存在的文件夹。
客户端导出后，只安装结果中的 data_definitions 文件，并在单独的 GWENT 安装
中测试。请保留编辑器生成的备份包。替换游戏文件前先关闭游戏；恢复多个包时，
请按安装顺序的相反顺序恢复。

5. 安全使用

- 保持原始客户端不变，在单独的 GWENT 安装中测试导出结果。
- 在不再需要回滚之前，不要删除备份包。
- 不要修改被禁用的卡牌或参数。
- 如果编辑器提示源文件在当前会话之外发生变化，请停止操作并重新打开客户端，
  不要覆盖外部修改。
- 安装游戏数据或媒体文件前，先备份测试客户端。
- 编辑器会验证受支持的数据结构，但不能保证游戏平衡或所有游戏内交互；
  请在游戏中验证修改效果。
