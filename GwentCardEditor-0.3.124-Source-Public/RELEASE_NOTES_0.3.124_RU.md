# GWENT Card Editor 0.3.124

Исправлена ошибка запуска редактора. В `UiText` дважды объявлялись пять ключей локализации для общего отката графических изменений. Создание словаря локализаций завершалось исключением `ArgumentException`, из-за чего показывалось сообщение `The type initializer for 'GwentCardEditor.UiText' threw an exception`.

Удалён повторный блок. Функция общего отката графических изменений и тексты локализации сохранены.
