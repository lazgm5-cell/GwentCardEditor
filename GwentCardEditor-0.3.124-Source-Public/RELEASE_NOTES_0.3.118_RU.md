# Версия 0.3.118

- Кнопка в главном окне переименована в «Проверить изменения», чтобы обозначить открытие списка правок.
- Кнопка в окне проверки подтверждает правки и запускает создание пакета для установки.
- Инструкция в окне проверки явно сообщает, что экспорт создаёт пакет, а исходный клиент не изменяет.
- Если пользователь отменит выбор папки для пакета, правки останутся в проекте и их можно экспортировать позднее.
