# Версия 0.3.123

- При первом открытии клиента редактор сохраняет неизменённую исходную копию `data_definitions` в `%LOCALAPPDATA%\GwentCardEditor\DefaultDataDefinitions`. Копия привязана к пути клиента, проверяется при каждом запуске и не заменяется автоматически. Кнопка «Открыть исходную базу» показывает её в Проводнике.
- Во вкладке «Оформление» добавлен общий откат установленных графических изменений: арта карт, рубашек, рамок и глобального оформления.
- Перед восстановлением проверяются все пакеты и контрольные суммы. Изменения откатываются в обратном порядке; при конфликте ни один файл не перезаписывается.
