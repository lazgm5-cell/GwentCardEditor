# Fiery Fiend с анимацией: отдельный эксперимент 0.1.1

Исправлен перенос параметров текстур: огонь и круговой градиент используют исходный Clamp,
а шумовые текстуры сохраняют Repeat. Также сохранены исходные фильтрация, анизотропия и смещение mip.
Это устраняет известное отличие от источника; исчезновение лишнего фрагмента нужно проверить в игре.

Это не подтверждённая функция публичного редактора. Основная версия 0.3.52 и статичные рамки не меняются.
Плагин заново создаёт шесть объектов Fiery Fiend в текущем Unity 2022: две стороны рамки,
огонь, добавочный огонь, глаза и свечение. Старый Unity-бандл не загружается в игру.
Используются исходные геометрия, текстуры, параметры и ключевые слова материалов,
но родной шейдер ShaderLibrary/Generic/GwentStandard из текущего GWENT.

Сцена рисуется в отдельную текстуру 512x1024 с частотой до 20 кадров/с и передаётся штатному
отрисовщику рамки. Эта текстура общая для тестовых представлений, не создаётся заново на каждую карту.
Арт, числа, статусы, звук, data_definitions, global и каталог ресурсов не переписываются.
Нужен уже установленный BepInEx IL2CPP. В оригинальном клиенте его нет; для первого теста подходит
`G:\Games\Gwent_Offline_Test`. Загрузчик автоматически не устанавливается.

## Ограничение первого теста

Только Кельтуллис, ID 202103. Откройте её увеличенный просмотр в коллекции и подождите пару секунд.
Перед применением рамки плагин проверяет, что отрисовка непустая и два кадра различаются.
При ошибке плагин оставляет штатную рамку и записывает диагностику в BepInEx/LogOutput.log.
Движение пикселей не доказывает правильное расположение и цвет эффектов: это нужно проверить глазами.
Ориентация, альфа-смешивание, яркость, пауза, закрытие и повторное открытие пока не проверены в игре.
Отключите другие плагины, которые подменяют рамки тестовой карты.

## Установка и удаление

Закройте все запущенные клиенты GWENT. Из PowerShell в этой папке:

```powershell
.\Manage-FieryFiend.ps1 -Action Install -ClientPath 'G:\Games\Gwent_Offline_Test'
.\Manage-FieryFiend.ps1 -Action Status -ClientPath 'G:\Games\Gwent_Offline_Test'
.\Manage-FieryFiend.ps1 -Action Remove -ClientPath 'G:\Games\Gwent_Offline_Test'
```

Установка создаёт только отдельную папку `BepInEx/plugins/GwentCardEditor.FieryFiend.Experimental`.
Существующая папка не перезаписывается. Удаление проверяет все контрольные суммы до первой записи
и удаляет только файлы данного пакета. Изменённые файлы блокируют удаление; посторонние файлы сохраняются.
После удаления перезапустите игру. Оставшаяся пустая папка сама по себе не включает плагин.
Если после удаления остались диагностические PNG или другие файлы, папка сохраняется.
Перед повторной установкой переместите её в архив: установщик намеренно не перезаписывает существующую папку.

При первом рендере в папке плагина появляются `frame-0.png` и `frame-1.png`.
Если что-то выглядит неправильно, нужны эти два изображения и фрагмент LogOutput.log с Fiery Fiend.
Пока не подтверждён этот тест, анимация не включается сразу для всей коллекции и не добавляется в основной интерфейс.
