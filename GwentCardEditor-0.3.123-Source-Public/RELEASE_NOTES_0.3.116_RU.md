# Версия 0.3.116

- Изменения карты автоматически переходят в общий черновик при выборе другой карты; подтверждать каждую карту отдельно больше не нужно.
- Кнопка «Применить изменения» открывает список правок, сгруппированный по картам.
- В списке можно открыть карту для дальнейшего редактирования или удалить все изменения выбранной карты.
- Если изменения на другой карте созданы связанным эффектом, окно указывает на карту-источник; их можно убрать вместе с правками источника.
- Отмена и повтор действий синхронизированы с общим черновиком. Изменения остаются в проекте и попадают в пакет GWENT только после отдельного экспорта.
- Удалён прежний инструмент «Пакетно изменить».
- В сводке изменений категории показываются понятными локализованными названиями, а броня — только числовым значением.
- В сводке добавлена кнопка «Сбросить все изменения»; сброс подтверждается и доступен для отмены.
- Автоматически добавленные тексты локализаций для начальных статусов и ключевых слов скрыты в сводке; ручные правки локализаций остаются видны.
- Значения фракций, второй фракции, редкости, рамки и основной категории в сводке показаны названиями, а не ID из файлов.
- Названия строк локализации и способности в списке изменений больше не выводят технические ID; логические значения используют локализованные подписи.
