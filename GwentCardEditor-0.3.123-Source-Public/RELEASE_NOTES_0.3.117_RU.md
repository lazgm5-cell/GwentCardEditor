# Версия 0.3.117

- Для импорта рубашек добавлен флажок «Применить изображение ко всем 7 рубашкам».
- Одно изображение устанавливается для всех поддерживаемых стандартных рубашек через один пакет.
- Общая текстура низкого качества обновляется один раз вместе с остальными файлами; она не теряется при последовательной обработке нескольких рубашек.
- Пакет проверяет все затронутые файлы, сохраняет резервную копию и поддерживает откат.
- Анимации и неподдерживаемые рубашки остаются без изменений.
- Переведены новые подписи и уточнена область применения для всех 13 языков интерфейса.
- Уточнено в README: бронзовые и золотые рамки в «Общем оформлении карт» применяются глобально и независимо.
