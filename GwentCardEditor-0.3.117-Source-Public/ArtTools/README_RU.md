# Прототип замены обычного арта

Начальные статусы вновь отложены по просьбе пользователя. Текущий этап: замена
рисунка существующей карты, а не импорт новой карты или механики.

`art_swap.py` собирает пакет из локальных ресурсов двух клиентов, не копируя старую
Unity-сериализацию в новый клиент. Картинка декодируется из донора и записывается
в существующий Texture2D назначения с его именем и идентификатором объекта.
Графы, шаблоны, локализация, звук и premium-ресурсы не редактируются.

Сейчас проверена сериализация назначения Unity 2022.3.62f2, четыре качества обычного
арта и статические ресурсы без зависимостей. Общий ArtId у нескольких шаблонов
блокируется: для него потребуется отдельное переназначение ресурса, а не скрытая
замена сразу нескольких карт. Несовпадение пропорций блокируется без обрезки.
Китайские/альтернативные варианты ресурсов этим прототипом отдельно не покрываются.

Варианты команд: `build`, `verify`, `install`, `restore`.
Сборке нужны UnityPy и Pillow; проверка SHA256/установка/восстановление используют
только стандартную библиотеку Python. Для текущей лаборатории зависимости уже есть
в `G:\Games\Gwent_Offline_Test\BetaImportLab\deps`.

Пример сборки:

```powershell
python art_swap.py --dependencies "G:\Games\Gwent_Offline_Test\BetaImportLab\deps" build --source "G:\Games\GWENT - Rogue Mage" --source-card 202721 --target "G:\Games\Gwent_Offline_Test" --target-card 202103 --output "новая папка пакета"
```

Выходная папка должна быть новой и находиться вне StreamingAssets. Собранные файлы
не устанавливаются командой build. verify проверяет формат и SHA256. Перед install
и restore проверяются текущие SHA256 и отсутствие процесса Gwent.exe.
При обычном исключении установки уже заменённые файлы возвращаются; это не обещание
транзакционной защиты от отключения питания. Полная резервная копия остаётся в пакете.

В версии 0.3.41 путь для своих изображений подключён к вкладке «Арт»: выбор файла,
кадрирование, экспорт пакета, подтверждение установки и восстановление. Обработка
выполняется локально через поставляемый ArtRuntime, без ручной установки Python.
Режим image-build получает подготовленный кадр с пропорциями 128:178 и сохраняет
нижнюю служебную область стандартной игровой текстуры. normalize принимает PNG,
JPEG и WebP, учитывает EXIF-поворот и удаляет метаданные. Анимированные файлы, файлы
больше 50 МБ и изображения больше 25 мегапикселей не принимаются.
Режим CLI build для прямого переноса из Rogue Mage остаётся разработческим.
Автоматическое переназначение общих ArtId и работа с анимациями не добавлены.
